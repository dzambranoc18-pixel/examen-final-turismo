# Portal Web: Agencia de Turismo Tonsupa Paraiso Tropical

**Nombre del Estudiante:** Danny Aracely Zambrano Carvajal  
**Lugar Turístico Asignado:** Tonsupa – Esmeraldas (Playa, hoteles, gastronomía y deportes acuáticos)  
**Asignatura:** Diseño de Sitios Web / Examen Práctico  

---

## Descripción del Proyecto
Tonsupa Paraiso Tropical es un portal web desarrollado para una agencia de turismo. Promociona los principales atractivos turísticos, servicios gastronómicos, opciones de hospedaje y actividades de aventura acuática en la playa de Tonsupa, provincia de Esmeraldas, Ecuador.

## Tecnologías Utilizadas
* **HTML5:** Estructuración semántica (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) y formularios accesibles.
* **CSS3:** Hoja de estilos externa, Box Model, Flexbox, CSS Grid, variables CSS, efectos hover y diseño adaptativo con `@media queries`.
* **Git & GitHub:** Control de versiones del código fuente.
* **GitHub Pages:** Despliegue e hosting web público.
